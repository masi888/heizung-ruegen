# Content Acceptance Checklist

Stand: 2026-04-07

Diese Checkliste soll nach Integration der Content-Dateien in die Next.js-App abgearbeitet werden.

## Navigation / Routen

- [ ] Startseite `/` vorhanden
- [ ] Leistungsuebersicht `/leistungen` vorhanden
- [ ] Servicepages `/heizung-ruegen`, `/waermepumpen-ruegen`, `/wartung-service`, `/badsanierung-ruegen`, `/klimaanlagen-ruegen` vorhanden
- [ ] Conversionseiten `/notdienst`, `/kontakt` vorhanden
- [ ] Vertrauensseite `/ueber-uns` vorhanden
- [ ] Supportseiten `/faq`, `/ratgeber` vorhanden
- [ ] Wissensseiten fuer Waermepumpe, Wartung, Badmodernisierung vorhanden
- [ ] Rechtseiten `/impressum` und `/datenschutz` vorhanden

## Copy / Messaging

- [ ] Startseiten-H1 betont moderne Heiztechnik + verlässlichen Service auf Ruegen
- [ ] 24h-Notdienst ist im sichtbaren oberen Seitenbereich erkennbar
- [ ] Vertrauenssignale enthalten seit 1990, Familienbetrieb, Bosch Premium Partner, Ruegen-Bezug
- [ ] Keine erfundenen Bewertungen, Referenzen oder Projektzahlen eingebaut
- [ ] Ruegen / Breege / regionaler Einsatz klar erwaehnt

## Wartung

- [ ] Drei Wartungsoptionen sichtbar
- [ ] Datei-Upload bzw. Hinweis auf Typenschild-/Anlagenfoto sichtbar
- [ ] Formularfelder decken mindestens die in `maintenance-packages.json` genannten Kerndaten ab
- [ ] Oeffentliche Preislabels nur als Platzhalter/`ab`-Preis eingebaut, bis kaufmaennische Freigabe vorliegt

## FAQ / Wissen

- [ ] FAQ beantwortet Einsatzgebiet, Notdienst, Wartung, Waermepumpe, Bad, Klima
- [ ] Ratgebermodul auf Startseite oder Hub sichtbar verlinkt
- [ ] Drei Wissensartikel enthalten fachliche CTA zur passenden Servicepage oder Anfrage

## SEO / Konsistenz

- [ ] Title und Description pro Kernseite eingebunden
- [ ] Sichtbare Aussagen und strukturierte Daten widersprechen sich nicht
- [ ] Interne Links von Servicepages zu Kontakt / FAQ / Ratgeber gesetzt
